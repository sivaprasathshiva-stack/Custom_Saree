# NILA Provenance

- Nila is a fictional, AI-generated brand character created for VELVOREA. She is not a real person.
- The nine reference images catalogued in `NILA_REFERENCE_REGISTRY.md` are the initial canonical visual reference set, supplied to this repository on 2026-09-19.
- Nila is not intended to represent, and must never be presented as representing, any real individual — living, historical, or public figure.
- Future AI-generated Nila images should be derived from this approved reference system (see `NILA_GENERATION_RULES.md`), not created independently from scratch.

The following are intentionally **not** stated anywhere in this documentation set, because they cannot be established from the reference images and must not be invented:
- A model identity or real person's name
- A real-world biography
- A modelling agency or representation
- An employment history
- Any biometric measurement (height, weight, exact age, precise facial measurements, HEX skin values)

If any of the above is ever needed for a specific business purpose (e.g. a legal/licensing requirement), it must come from an actual documented decision by the VELVOREA team, recorded as a dated entry in `NILA_CHANGELOG.md` — not inferred or fabricated by any future AI session working on this repository.
